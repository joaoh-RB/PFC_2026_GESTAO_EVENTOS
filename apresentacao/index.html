O problema

O que o Symplosio soluciona

Centraliza divulgação, inscrição e gestão de eventos acadêmicos em um único fluxo digital, com papéis claros e rastreabilidade.

1. Divulgação fragmentada

Eventos espalhados em murais, grupos e planilhas, sem um canal oficial.

2. Inscrição e presença manuais

Controle difícil de vagas, listas e confirmação de participação.

3. Gestão sem rastreio

Grupos, documentos e aprovações sem histórico claro entre perfis.

4. Falta de visão gerencial

Instituições sem indicadores consolidados de engajamento acadêmico.

Stack

Tecnologias utilizadas

Front-end, back-end e serviços em nuvem.

Front-end
  • React 19 + TypeScript + Vite
  • Tailwind CSS 4 + shadcn/ui
  • React Router, Hook Form, Zod, Axios
  • Hospedagem na Vercel
Back-end
  • .NET 10 + C#
  • EF Core + PostgreSQL (Npgsql)
  • FluentValidation + Swagger + xUnit
  • Hospedagem no Render (Docker)
Serviços
  • Supabase — banco e arquivos
  • SendGrid — e-mails
  • Google Calendar — sincronização
  • Vercel + Render
